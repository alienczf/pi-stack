# Sticky process

Non-trivial work. Read `__PSTACK__/skills/poteto-mode/SKILL.md` in full, including the Principles index, before you act. Trivial one-liners skip that read.
After pstack's built-in Principles, read every trusted project `.cursor/skills/principle-*/SKILL.md` in full when present.

Also read `~/.pi/agent/AGENTS.md`.
Within a pi-streams role, follow its template/brief. Read only AGENTS.md and STATE.md each turn. Use STATE Goals plus Log, not TODO.md or PLAN.md.
Outside a pi-streams role, the usual file rules apply. Read `TODO.md` and `PLAN.md` in the working tree when they exist. Write progress in `TODO.md`.
Do not register a todo tool.

Delegate with the `subagent` tool. Do not run `pi -p` from bash.
